# Inquiry-Based Commerce Mentor — RAG Prototype (TOCD + RTAO)

A RAG tool for **Project #5: Inquiry-Based Commerce Mentor**, grounded in
NCERT Class 11–12 Commerce Stream textbooks (Business Studies, Accountancy,
Economics). It implements **two separate, swappable prompting strategies**
so you can compare them for your homework:

- **TOCD** (Task / Objective / Context / Deliverable) — the framework the homework asks for.
- **RTAO** (Role / Task / Audience / Output) — the template from your CSC530 slides.

Both retrieve from the same knowledge base; only the system-prompt structure differs.

---

## 0. Check your Ollama install and models first

Open a terminal on **your own machine** (not this sandbox) and run:

```bash
# 1. Check Ollama is installed and see its version
ollama --version

# 2. See which models you've already downloaded
ollama list
```

You'll get output like:
```
NAME                    ID              SIZE      MODIFIED
llama3.2:latest         a80c4f17...     2.0 GB    3 weeks ago
nomic-embed-text:latest 0a109f...       274 MB    3 weeks ago
```

- If you see a **chat/instruct model** (e.g. `llama3.2`, `llama3.1`, `mistral`, `gemma2`, `qwen2.5`) — note its exact name.
- If you see an **embedding model** (e.g. `nomic-embed-text`, `mxbai-embed-large`) — note its exact name.
- If either is missing, pull them:
  ```bash
  ollama pull llama3.2
  ollama pull nomic-embed-text
  ```

Then open `config.py` in this project and set `CHAT_MODEL` and `EMBED_MODEL`
to match **exactly** what `ollama list` showed you.

Make sure Ollama is actually running (it usually runs as a background
service once installed; if not, start it):
```bash
ollama serve
```
By default it listens on `http://localhost:11434` — that's what `config.py` points to.

## 1. Set up the Python project

```bash
cd rag_commerce_mentor
python -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Build your knowledge base

Put your curated NCERT Commerce content into the `data/` folder as `.pdf`
or `.txt` files — e.g. `business_studies_ch1.pdf`, `accountancy_ch3.pdf`,
`economics_ch5.txt`. Keep it curated (only chapters/topics you actually want
the tool to answer from) — this is the "what's included / excluded" decision
the assignment's CONTEXT section asks you to justify.

Then run the ingestion pipeline (Documents → Cleaning → Chunking → Embedding → Vector Store):

```bash
python ingest.py
```

This creates `store/vector_store.json`. Re-run this any time you add/change files in `data/`.

## 3. Run the app

```bash
python app.py
```

Open **http://localhost:5000** in your browser. Type a question, toggle
between **TOCD** and **RTAO** mode, and compare the answers + retrieved
sources shown underneath.

## 4. Evaluate

Use `eval_questions.md` as your test set (5 straightforward, 5 complex,
3 insufficient-information, 2 hallucination-stress questions, per the
assignment). Run each one in both TOCD and RTAO mode, and fill in the
results table for your Evaluation Report.

## Project structure

```
rag_commerce_mentor/
├── config.py           # model names, chunk size, top_k — EDIT THIS FIRST
├── ingest.py            # Documents -> Cleaning -> Chunking -> Embedding -> Vector Store
├── vectorstore.py        # cosine-similarity search over the JSON vector store
├── rag_engine.py         # retrieval + build_tocd_prompt() + build_rtao_prompt() + generate()
├── app.py                # Flask backend (/api/ask)
├── templates/index.html  # web UI with TOCD/RTAO toggle + source display
├── requirements.txt
├── eval_questions.md      # test question set + results table template
├── data/                  # <- put your NCERT PDFs/txt here
└── store/vector_store.json  # generated by ingest.py
```

## Architecture (for your submission diagram)

```
User (browser)
   -> Web Interface (Flask + HTML/JS, templates/index.html)
      -> Query Processing (app.py: /api/ask)
         -> Retrieval (rag_engine.retrieve -> embed_query via Ollama nomic-embed-text)
            -> Vector Database (vectorstore.py: JSON store + cosine similarity, numpy)
               -> Retrieved Context (top-k chunks with source/page)
                  -> LLM (Ollama /api/chat, e.g. llama3.2) with TOCD or RTAO system prompt
                     -> Response (answer + cited sources)
                        -> User
```

## Notes on the TOCD prompt used

```
TASK: Answer commerce questions using retrieved NCERT content; guide via inquiry
      (Observation -> Question -> Hypothesis -> Analysis -> Conclusion) where useful.
OBJECTIVE: Accurate, concise, evidence-grounded answers; reduce hallucination;
           build inquiry skills rather than passive recall.
CONTEXT: Retrieved passages are from NCERT 11th/12th Commerce textbooks only.
DELIVERABLE: guiding question -> direct answer -> supporting explanation ->
             sources -> explicit "insufficient information" fallback.
```
See `rag_engine.py -> build_tocd_prompt()` and `build_rtao_prompt()` for the exact text used.
